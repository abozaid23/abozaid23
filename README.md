# Yousef Nasser Abozaid

Computer Science at Nile University, Cairo. I build operations software — the unglamorous systems that run fleets, bookings, and schedules.

That's not an accident of taste. I grew up in a real-estate development company and have spent the last few years supervising crews and procurement there, so I keep ending up at the same problem: the work is real, the coordination is on paper, and nobody's built the tool.

---

### What I'm building

**[SharpMaintain](https://github.com/abozaid23/sharpmaintain)** — multi-tenant fleet maintenance system.
FastAPI + Flutter + React. Offline-first capture for mechanics with no signal, tenant isolation from the first commit, bilingual AR/EN with real RTL. 115 backend tests, more test code than application code, and a security audit that found and fixed cross-tenant escalation and CSV formula injection.

**[Washly](https://washly-one.vercel.app)** — car wash booking platform. *(private repo, live product)*
Book a wash in seconds, track the worker, pay cash on site. Arabic-first. Currently in pilot conversations with operators in Cairo.

**[Clinic Management System](https://github.com/abozaid23/clinic-management-system)** — Java Swing + PostgreSQL, six-person team.
Patients, doctors, appointments with conflict detection. Every query parameterised — no string-concatenated SQL anywhere. Built for CSCI 217.

**[Campus Navigation](https://github.com/abozaid23/campus-navigation-system)** — graph representations and BFS in Python.
Adjacency list, matrix, edge list, and the conversions between them. Built for Discrete Mathematics with one teammate.
